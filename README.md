# HTTP Proxy Server

一个使用 Python 3 标准库实现的轻量 HTTP/1.1 代理服务器，支持常见的 `GET`、`POST`、`HEAD` 请求，并通过 `CONNECT` 隧道转发 HTTPS 流量。项目包含简单的多线程连接处理、内存 LRU 缓存和访问日志。

## 功能

- 为每个客户端连接创建独立线程。
- 转发 HTTP 请求并返回上游响应。
- 使用 `CONNECT` 方法建立 TCP 隧道，可供 HTTPS 代理连接使用。
- 缓存符合条件的 `GET` 响应：仅缓存状态码为 `200` 且响应体不超过对象大小限制的响应。
- 使用 LRU（最近最少使用）策略管理内存缓存。
- 将请求摘要输出到终端，并追加写入 `log.txt`。

## 环境要求

- Python 3
- 无需安装第三方依赖，仅使用 Python 标准库

## 启动

```sh
python3 proxy.py <port> <timeout> <max_object_size> <max_cache_size>
```

参数均为整数：

| 参数 | 说明 |
| --- | --- |
| `port` | 代理监听端口 |
| `timeout` | socket 操作和 CONNECT 隧道等待的超时时间（秒） |
| `max_object_size` | 单个响应体允许进入缓存的最大大小（字节） |
| `max_cache_size` | LRU 缓存总容量（字节） |

例如，启动监听在 8080 端口的代理，超时设为 10 秒，单个缓存对象上限为 1 MiB，缓存总容量为 10 MiB：

```sh
python3 proxy.py 8080 10 1048576 10485760
```

启动后，程序会在终端显示监听端口。按 `Ctrl+C` 可停止服务器。

## 配置客户端

将客户端的 HTTP/HTTPS 代理设置为 `127.0.0.1:8080`。也可用 curl 发起请求：

```sh
curl -x http://127.0.0.1:8080 http://example.com/
curl -x http://127.0.0.1:8080 https://example.com/
```

HTTPS 请求通过 `CONNECT` 建立隧道；代理转发加密流量，不解密 HTTPS 内容。

## 缓存与日志

只有成功返回 `200` 且响应体大小符合 `max_object_size` 的 `GET` 响应会进入进程内缓存。缓存以规范化后的 URL 为键，容量达到 `max_cache_size` 后会从最近最少使用的条目开始淘汰。缓存不会写入磁盘，服务器重启后清空。

每个请求会记录客户端地址、缓存标记、时间、请求行、状态码和响应大小。日志同时打印到终端，并追加写入启动目录中的 `log.txt`。

## 安全说明与限制

- 服务器绑定到所有网络接口（`0.0.0.0`），而且没有客户端认证。请只在受控的本机或可信网络环境运行；不要将它直接暴露到公网。需要时请使用防火墙限制访问。
- 这是用于学习 HTTP 代理、socket、线程和缓存的简化实现，不是面向生产部署的通用代理服务器。
- HTTP 解析、连接管理和响应处理仅覆盖常见场景；复杂或非标准的 HTTP 流量可能无法正确处理。
- 程序会为每个客户端连接创建线程，未设置连接数上限或访问控制。
